### 3. Proof-of-Work 不等于挖矿
- 这里的 PoW = 公开可验证的学习产出证明
- GitHub commit 历史、Etherscan tx hash、daily note 都是 PoW
- 审核者关注：这是谁？学了什么？是否持续？

- 入口：WCB Learning 页面 → 找到任务 → Submit Evidence
- 证明格式：GitHub 链接 / X 链接 / 公开笔记 / tx hash / 截图
- 可选附加说明，描述仓库内容和学习进度
