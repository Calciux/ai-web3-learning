## 学到的重点

- Foundry 开发类比 C 开发：写 .sol → forge build → forge create 部署 → cast call 调合约
- Foundry 本身是 Rust 写的，但开发全用 Solidity，不碰 Rust
- ERC-8183 状态机：Open→Funded 后 Client 失去 reject 权，只 Evaluator 能裁决—保护 Provider
- expectedBudget 参数防止 front-run 攻击
- claimRefund 是唯一不可 Hook 的函数——安全底线
- optParams 透传机制：合约不解码，直接给 Hook
