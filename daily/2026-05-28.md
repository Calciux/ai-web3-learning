## 学到的重点

### Solidity 语法关键字

- `external` — 仅合约外部可调用
- `public` / `internal` / `private` — 权限控制四象限
- `payable` — 函数可接受 ETH
- `require` — 条件检查，失败则 revert
- `view` — 声明只读，不改变链上状态
- `emit` — 触发 event，将日志写入 receipt

### Event 与 ABI

- event — 链上日志，通过 emit 触发，存入 transaction receipt
- topic[0] — keccak256(事件签名)，自动生成
- topic[1..3] — indexed 参数，最多 3 个，可被 Etherscan 高效搜索
- data — 非 indexed 参数，不可直接搜索
- anonymous — 事件名不存入 topic，节省 gas
- ABI — 合约说明书：函数签名、state mutability、event 定义

### WETH 合约分析

- deposit() — 存 ETH 换 WETH（任何人可调，非特权函数）
- receive() — 兜底函数，无 data 时默认触发
- withdraw() — 销毁 WETH 取回 ETH；require 前置检查
- approve() — 授权他人花费（信用卡副卡）
- transfer() / transferFrom() — 转账；transferFrom 有 allowlance 检查
- totalSupply() — 只读，= address(this).balance
- 无 owner / 无 mint / 无 pause / 无 upgrade — 零特权合约

### 权限函数清单

- owner/admin — 超级管理员，单点故障风险
- mint — 凭空增发，稀释所有持有者
- burn — 销毁代币，风险较低
- pause/unpause — 冻结/解冻所有转账
- upgrade — 替换合约逻辑，approve 额度不会自动取消
- blacklist — 封禁地址，违背去中心化
- setFee — 调整手续费，可提高至 100%
- withdrawToken — 提取误转入代币

### WETH 风险边界

- 核心矛盾：无 owner = 安全（无人 rug），但也 = 零容错（有 bug 无法修复）
- 具体风险：withdraw() 无重入保护（仅靠 transfer() 的 2300 gas 限制缓解）
- 设计哲学：WETH 选择「永远不改」，上线 8 年未更过一行代码
