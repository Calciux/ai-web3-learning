## 学到的重点

- ERC-4337 不改变以太坊共识层，靠链上合约 + 链下 Bundler 实现
- UserOperation 签名 ≠ EOA 交易签名 — 中间有 Bundler + EntryPoint 两关审核
- Bundler 赚手续费差价 + 承担 bundle 回滚风险
- Guardian 只能换 Owner 不能动资产 — 换锁不搬家
- Input Data 可反推函数参数（MethodID + ABI-encoded args）
- EOA 可以由脚本驱动（链下），但链上没有可编程规则（限额/延时/多签）
