## 学到的重点

- **EIP-712 > EIP-191**：CAW 钱包原生支持 EIP-712 `message_sign`，可直接生成结构化签名，无需 EIP-191 的 hack
- **CAW 跨环境钱包**：PROD 环境钱包未配对 → 可配置 `always_review=false` 自动放行；DEV 环境配对 → 需人工审批。BiddingHook 场景中 Provider 用 PROD 环境实现自动竞价
- **Escrow 数据编码链路**：`setProvider(optParams)` → Escrow 包装 `abi.encode(caller, provider, optParams)` → Hook 解码两层 → 验签。v3 兼容 unwrapped 格式
- **BiddingHook 防作弊三层**：签名绑 jobId（防重放）+ 绑 price（防篡改）+ ecrecover 恢复 signer == provider（防冒名）
- **A2A Economy 本质**：不是新合约，是同一套 ERC-8183 支付原语被 N 个 Agent 复用。02 基建 + 05 叙事 = 完整故事
