## 学到的重点

- GitHub 提供 ssh.github.com:443 作为 SSH-over-HTTPS 端点，绕过企业/ISP 对 22 端口的封锁
- nc -X connect -x <proxy> %h %p 可让 SSH 走 SOCKS/HTTP 代理
- git add 支持按目录批量添加：`git add contracts/ docs/ scripts/ test/`
- **patchelf** 可修改 ELF 二进制的动态链接器（interpreter）和 rpath，不替换系统 GLIBC 就能跑新版二进制
- solc 0.8.21 Natspec.cpp(85) 有编译器断言 crash bug，0.8.25 已修复
- Forge nightly build 可通过 GitHub Releases 直接下载（`foundry_nightly_linux_amd64.tar.gz`）
- forge 下载 solc 二进制需走 HTTPS_PROXY（`export HTTPS_PROXY=http://192.168.144.1:7890`）
- 单元测试 vs 集成测试边界：单元测一个函数一个行为分支，跨多函数串联是集成测试
