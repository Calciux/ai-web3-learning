# 从 VC 角度，如何更好打磨项目
## 务实:看落地情况
+ 更加关注: PMF(Product-Market Fit)/留存/CAC(Customer Acquisition cost)/商业化
+ **把握timing**:学习+execution

## 融资之前,回答以下问题
- 项目是否落地？
- 有多少用户？
- 是否能实现商业闭环？
- 获客的渠道和成本是什么？
- 目前是否盈利？
- 为什么要找 VC 融资？
- 底层的大模型迭代后，项目还能存在的意义吗？
- 项目的壁垒是什么？

## 看重人/Team
+ 行业理解深度: AI锦上添花, 但需要对本领域有积累
+ execution > idea
+ 合伙人(凝聚力/能力的互补)
+ 加分项:connection/个人魅力/行业影响力

## VC关注点(能否为投资人带来回报)
+ 增长潜力/盈利
+ 项目的核心优势能否保持

### 对我的项目展示
1. 展示清楚项目的真实痛点:ERC-8183到底解决了一个什么样的问题,处于哪个位置
2. execution:一定要做出demo,一个链上验证更有说服力
3. 项目不应该做一个AI套壳,而是应该关注这个标准本身
4. 提出项目的愿景,说明我hackathon项目本身是注重底层原理的,是可以被广泛采用的
