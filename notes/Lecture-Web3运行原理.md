# Web3 运行原理

## 交易生命周期

```
Wallet → RPC → Mempool → Builder → Validator → Block
```

---

## Who Are You — 身份体系

| 组件 | 说明 |
|------|------|
| **Private Key（私钥）** | 你的数字身份证明，**必须保密** |
| **Public Key（公钥）** | 由私钥推导产生，可公开 |
| **Mnemonic / Seed Phrase（助记词）** | 一组单词，可以生成多个私钥；但**一个私钥仅对应一个助记词路径** |
| **Address（地址）** | 公开账户标识，衍生链：`private key → public key → address` |
| **Signature（签名）** | 用私钥对交易签名，证明这笔交易是你授权的 |

> **关键认知：Wallet 仅仅是用来保存/调用密钥、构造交易、发起签名的工具——资产并不在钱包上。真实余额存储在链上账本中。**

---

## What Do You Want To Do — 操作类型

### Transaction（交易）

一段你授权网络执行某一动作的指令。

| 字段 | 作用 |
|------|------|
| **Gas** | 交易手续费，支付给验证者 |
| **Nonce** | 交易序号，防止重放攻击 |
| **Signature** | 你的签名，证明你授权了这笔交易 |

### Contract（智能合约）

**写在链上、能被交易触发的代码。**

- 一旦部署，不可篡改
- 由交易调用执行
- 执行结果由全网验证

---

## Why Trust The Outcome — 信任链

| 层级 | 作用 |
|------|------|
| **节点传播** | 交易通过 P2P 网络广播到全节点 |
| **验证者出块（PoS）** | Validator 打包交易、提议区块、投票确认 |
| **Finality（最终确定性）** | 区块经过足够多的确认后不可逆 |
| **合约状态** | 智能合约的执行结果由全网节点共同维护和验证 |
