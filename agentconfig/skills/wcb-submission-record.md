# wcb-submission-record

编译 WCB（AI×Web3 School）任务提交记录（配置记录/运行记录），从对话历史中提取证据。

## 五要素结构

| # | 要素 | 内容 |
|---|------|------|
| 1 | 选择的 Agent / AI 工具 | 工具、模型、环境、提供商 |
| 2 | 让 Agent 完成的学习任务 | 委派给 Agent 的学习任务 |
| 3 | 关键 prompt 或配置说明 | 关键 prompt、配置或系统偏好 |
| 4 | 一次成功输出记录 | 成功输出 + 具体证据（commit hash、文件路径） |
| 5 | 人工复核、修正或拒绝记录 | 至少一次人工审查/纠正/拒绝 AI 输出的案例 |

## 工作流

1. 检查 `notes/Agent配置运行记录.md` 是否已存在
2. 用 session_search 跨会话搜索证据
3. 写入五要素结构文档
4. 展示给用户审阅
5. 用户确认后 commit + push

## 陷阱

- 注意旧文件可能只覆盖一个 session
- 扩展时要跨所有会话搜索
- 纠正案例要有用户原话作为证据
- 第五部分应覆盖 4+ 种不同纠正类型
