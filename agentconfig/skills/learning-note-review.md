# learning-note-review

检查并补充概念学习笔记，每个概念必须包含三要素结构。

## 三要素

1. **一句话解释** — 概念的一句话定义
2. **具体例子** — 具体、真实的用例
3. **常见误区或使用边界** — 常见误解、误用模式或概念边界

## 工作流

### 阶段 1：补充（patch）
1. 读取笔记，识别每个概念标题
2. 检查缺失的三要素
3. 用 `patch` 工具在概念标题下插入缺失内容
4. **只添加不删除** — 使用 patch 而非 write_file
5. 验证：原内容未删除，每个概念都有三要素

### 阶段 2：覆盖（write_file）
当用户提供完整替换文本时（说"覆盖写入"或粘贴完整新内容）：
1. 使用 write_file 整体覆盖
2. 不要用 patch
3. 接受用户的格式选择，不要强制加回显式标题

## 格式风格

用户偏好的最终格式是**紧凑型**。三要素自然融入文本，而非使用显式标题：
```
# 概念名
第一行是一句话解释。
+ 要点
+ ...
```

## 笔记仓库结构

```
ai-web3-learning/
├── notes/          # 知识笔记
├── daily/          # 每日打卡
```

## 陷阱

- 阶段 1 不要用 write_file（会覆盖原文件）
- 不要重新排序或重构用户的现有章节
- 不要删除用户的原始内容
- 不要合并概念
- 例子必须与用户领域相关（Web3/DeFi/智能合约等）
